# Photon PUN Multiplayer Project

A Unity multiplayer project focused on **Photon Unity Networking (PUN)**.

The central focus of this repository is the networking side of multiplayer development: using PUN to build a shared gameplay experience across connected clients.

## Project focus

**PUN networking is the core of this project.** The repository is intended to showcase work with Photon Unity Networking in a Unity multiplayer environment, with the networking implementation as its main technical focus.

When exploring the project, the key area of interest is how PUN is integrated into the game's multiplayer behaviour.

## Technology

| Technology | Role |
| --- | --- |
| Unity | Game development environment |
| Photon Unity Networking (PUN) | Core multiplayer networking technology |
